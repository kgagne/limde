# Brand icons: notice

The icons in this folder identify specific applications. The logos they depict are
trademarks of their respective owners. limDE is not affiliated with or endorsed by
any of them; each icon is used only to show which application a launcher or window
belongs to.

## Where they come from

- **Craft apps** (`*craft*.svg`, `craft-launcher.svg`): original limDE glyphs, MIT.
  Most are drawn from reference images limDE's author generated with Lumo, an AI image
  generator: each shows the subject of the app's own icon (an animal or object) but none
  traces storytold's artwork, and none uses the ArtCraft marks.
- **Simple Icons** (solid icons with a "Simple Icons" comment in the file): from
  [Simple Icons](https://simpleicons.org) 16.35.0, placed inside limDE's margin.
  Licence as recorded by Simple Icons: CC0-1.0 in this folder, CC BY-SA in `cc-by-sa/`,
  MPL-2.0 in `mpl-2.0/`.
- **Line drawings** (`btop`, `darktable`, `rawtherapee`, and `cc-by-sa/foot`,
  `cc-by-sa/papers`): simplified redraws made for limDE, for logos Simple Icons lacks.

- **Tailscale** (`tailscale.svg`, `tailscale-slash.svg`): the state icons of Tinybar's
  optional Tailscale button, not an app icon. Simple Icons 16.35.0's geometry (CC0-1.0),
  with the grey dots as reduced opacity, as Tailscale's brand toolkit (its press kit) asks,
  instead of Simple Icons' rings. Off is all dots grey, as Tailscale's own tray app shows
  it (`client/systray/logo.go`, BSD-3-Clause), plus limDE's Wi-Fi slash. Tailscale
  publishes no logo licence; the logo is used only to label the button that controls
  Tailscale. Tailscale is a registered trademark of Tailscale Inc.

## Not included

These owners do not allow modified or redrawn versions of their logos, so limDE
ships no icon for them and the apps keep their own: Firefox and Thunderbird (Mozilla),
Visual Studio Code (Microsoft), Signal, Steam (Valve), Claude (Anthropic), and the Ubuntu
logo (Canonical).

Blender's logo guidelines ask for the logo to be used unaltered. limDE includes the
Simple Icons version anyway, as other icon themes do. If a logo owner objects to any icon
here, open an issue and it will be removed.
