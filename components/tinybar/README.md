# Tinybar

limDE's panel: open windows (with the agent-web window always leftmost), Wi-Fi,
volume, brightness, battery, notifications and the clock. Python with GTK 4 and
gtk4-layer-shell, plus a small C helper (`toplevel-helper`) that lists windows through
the wlr foreign-toplevel protocol.

- Icons come from the icon theme (limDE's), as SVG; no icon fonts.
- Settings: `~/.config/tinybar/settings.toml`, optional. `first_app_id` picks the app
  that always sits leftmost (default `limde.AgentWeb`).
- Battery: the panel shows the time left; hover for the percentage, the live draw and
  a 3-hour average. Click it for a graph of the draw over the last 3 hours, 24 hours or
  7 days (arrows or Left/Right cycle through them). The data is the history Tinybar
  keeps in `~/.local/state/tinybar/history.jsonl`: 5-minute summaries while on
  battery, kept for 7 days. Gaps are time on mains power.
- Style: `~/.config/tinybar/style.css`, generated by the theme.
- Tests: `python3 -m unittest discover -s components/tinybar/tests`.
